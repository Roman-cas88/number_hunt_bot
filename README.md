# 🎯 Охота за числами — Telegram бот

Telegram-бот для групповой игры «Охота за числами».

## 📜 Правила игры

1. Игроки ищут числа строго по порядку от 1 до 100.
2. Чтобы заявить число, отправьте фотографию в чат.
3. Фото должно быть реальным объектом (не экран).
4. Участники голосуют за фото.
5. Если все проголосовали «Засчитать» — число засчитывается.
6. При голосе «Не засчитать» решение принимает администратор.
7. За каждое засчитанное число игрок получает 1 очко.
